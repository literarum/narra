# Narra — личный дневник

Приватный дневник, который работает прямо в браузере. Сервера нет: записи хранятся только на вашем устройстве, в этом браузере.

- Можно «установить» как приложение (значок в адресной строке или «Добавить на главный экран») и пользоваться без интернета.
- Данные привязаны к адресу сайта и браузеру. Перенос: Настройки → Данные → Резервная копия (лучше — «с паролем»), на другом устройстве загрузить её там же. Файл копии можно и просто перетащить в окно Narra.
- Нужен защищённый адрес (`https://…` или `localhost`): без него браузер не даёт шифровать записи.
- Нужен современный браузер: Safari/iOS 16.4+, Chrome/Edge 111+, Firefox 121+. В старом покажется сообщение с просьбой обновить.
- Клавиши: «?» показывает все сочетания, Ctrl/⌘ K — палитра команд.

## Для разработки

Все файлы лежат в корне репозитория, сборка не нужна (`.nojekyll` отключает лишнюю обработку на GitHub Pages). Шрифты (`*.woff`, лицензия в `OFL-fonts.txt`) идут в комплекте.

- Запуск: `npm run serve` (или любой статический сервер в папке) и `http://localhost:8765/`.
- Проверки: `npm test` (Node 20+, без зависимостей). Они же запускаются в GitHub Actions.
- Новый модуль нужно добавить в список `FILES` в `sw.js` — иначе он не будет доступен без сети (это проверяет тест).
- При выпуске версия меняется во всех адресах `?v=…`, в `sw.js`, `core.js`, `bootstrap.js`, `manifest.webmanifest`, `package.json` и здесь.

Версия приложения: 4.7.0.
