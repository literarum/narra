# Narra — личный дневник

Приватный дневник, который работает прямо в браузере. Сервера нет: записи хранятся только на вашем устройстве, в этом браузере.

- Можно «установить» как приложение (значок в адресной строке или «Добавить на главный экран») и пользоваться без интернета.
- Данные привязаны к адресу сайта и браузеру. Перенос: Настройки → Экспорт и резервная копия → скачать копию, на другом устройстве загрузить её там же.
- Все файлы лежат в корне репозитория, сборка не нужна (`.nojekyll` отключает лишнюю обработку). Шрифты (`*.woff`, лицензия в `OFL-fonts.txt`) идут в комплекте.
- Нужен современный браузер: Safari/iOS 16.4+, Chrome/Edge 111+, Firefox 121+. В старом покажется сообщение с просьбой обновить.

Версия приложения: 4.3.0.
