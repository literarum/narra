# Narra — личный дневник (версия для GitHub Pages)

Спокойный приватный дневник, который работает прямо в браузере. Сервера нет: записи хранятся только на вашем устройстве, в этом браузере.

- Сайт открывается по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`
- Можно «установить» как приложение (значок в адресной строке браузера или «Добавить на главный экран» на телефоне) и пользоваться без интернета.
- Данные привязаны к адресу сайта и браузеру. Чтобы перенести записи на другое устройство: Настройки → Экспорт и резервная копия → скачать копию, затем на другом устройстве загрузить её там же.
- Все файлы лежат в корне репозитория, сборка не нужна: GitHub Pages публикует их как есть (файл `.nojekyll` отключает лишнюю обработку).

Версия приложения: 4.2.0. Основная сборка с тестами и документацией — отдельный архив `narra-prototype-v4.2.zip`.
